# Intake Sub-skill

Turn raw inputs (grooming, kickoff, issues, bugs) into actionable work.

**Process:**
- Preserve original intent.
- Classify: bug, feature, chore, research, refactor.
- Extract: goal, user impact, requirements, constraints, acceptance criteria, dependencies, open questions.
- Use Matt discovery if ambiguity matters. Check repo/docs before asking user.
- Decide Planning directly vs optional Research.
- Produce clean task input.
- **Do not** implement or invent requirements. Avoid loading unrelated repository context.
