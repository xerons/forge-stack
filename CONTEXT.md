# ForgeStack context

## Canonical terms

- **Tracker:** The human-facing project system of record, such as Plane, Linear,
  or Huly.
- **Manager Agent:** The conversational ForgeStack role that turns human intent
  into tracker structure, specifications, plans, and proposed task breakdowns.
- **Orchestrator:** The ForgeStack role that executes an approved work item by
  selecting workers, coordinating dependencies, and collecting verification.
- **Worker Agent:** A role-specific coding, art, QA, or specialist agent that
  performs one bounded execution task.
- **Work Item:** A tracker record representing an epic, story, task, bug, or
  subtask.
- **Human Review:** The state in which agent work is complete from the agent's
  perspective and awaits human acceptance.
- **Blocked:** A state in which progress cannot continue without a decision,
  dependency, access, clarification, or correction.
- **Handoff:** A concise, evidence-backed report passed between Manager,
  Orchestrator, and Worker Agent roles.
